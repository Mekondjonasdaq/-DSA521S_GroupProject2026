## Project Description

This project implements a Campus Service Centre Simulation 
using fundamental data structures and algorithms in Java:

- **Queue** — Waiting line for students
- **Singly Linked List** — Student service records
- **Stack** — Postfix expression evaluation
- **Array** — Daily service statistics
- **Sorting Algorithms** — Selection, Insertion, Merge, Quick Sort

## How to Run the Program

### Requirements:
- Java JDK 17 or higher
- IntelliJ IDEA (or any Java IDE)
- Git (optional)

### Steps:

1. **Clone the repository:**
   git clone https://github.com/Mekondjonasdaq/-DSA521S_GroupProject2026.git

2. **Open in IntelliJ:**
   - File →  Open → Select the project folder

3. **Run the main menu:**
   - Open `src/MenuSystem.java`
   - Click the green button
   - OR press Shift + F10

4. **Other files you can run:**
   - `Main.java` — Test the queue
   - `TheSorting.java` — Test all sorting algorithms
   - `SortingExperiment.java` — Run the sorting experiment
   - `PostfixStack.java` — Test postfix evaluation
   - `ServiceList.java` — Test the linked list
